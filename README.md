## Deploy (next step)

### Frontend (Vercel / Netlify)
```bash
cd frontend
npm install
npm run build
```

### Backend (Railway / Render / VPS)
```bash
cd backend
npm install
npx prisma migrate deploy
npm run seed
npm run build
npm start
```

Set environment variables from `backend/.env.example`.
